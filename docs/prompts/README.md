# Prompts

The prompts behind the AI-assisted work on CampusGig. The report's AI-driven development section
refers to these files as evidence of how the team worked with AI tools.

| File | What it holds |
|---|---|
| `matching-agent.md` | The prompt and tools the job matching agent runs on, and why they are written that way. |
| `job-ad-assistant.md` | The prompts of the writer agent that rewrites a job ad. |
| `job-ad-critic.md` | The prompt of the critic agent that reviews the rewrite. |

The three agent prompts are copied from the code. If you change a prompt in the code, change it
here too. When a teammate uses AI for the report, the diagrams or the slides, add the prompt to
`development-prompts.md` and an entry to `../ai-log.md`.
